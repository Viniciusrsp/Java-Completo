# Java Completo — Programação Orientada a Objetos

Este repositório contém as soluções dos exercícios e projetos desenvolvidos durante o curso **Java Completo - Programação Orientada a Objetos + Projetos**, ministrado pelo prof. Nélio Alves (DevSuperior).

---

## 📚 Conteúdo do Repositório

O código está organizado pelas seções e tópicos do curso:

- **Estrutura Sequencial**: Exercícios básicos de entrada, saída e processamento de dados.
- **Estrutura Condicional**: Práticas com `if-else` e controle de fluxo.
- **Estruturas Repetitivas**: Exercícios focados em loops `while`, `for` e `do-while`.
- **Orientação a Objetos**: Classes, atributos, métodos, construtores, sobrecarga e encapsulamento.
- **Exemplos**: Demonstrações práticas e anotações feitas durante as aulas.
